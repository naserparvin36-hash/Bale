# Bale English — بله انگلیسی

نسخه‌ی اولیه‌ی بازطراحی‌شده‌ی Bale English با صفحه‌ی خانه‌ی رنگی و دوستان کارتونی.

## امکانات
- صفحه‌ی اصلی فارسی و راست‌چین با چهار کارت آموزشی
- حروف انگلیسی A تا Z و پخش نام حرف
- واژه‌ها با تصویرک، معنی فارسی و پخش تلفظ
- مکالمه‌های ساده با معنی فارسی و پخش صوت
- تمرین چندگزینه‌ای و امتیاز
- طراحی واکنش‌گرا برای موبایل و رایانه
- پوسته‌ی PWA و کش اولیه برای دسترسی آفلاین به فایل‌های اصلی

## اجرا
فایل `index.html` را در مرورگر باز کنید یا محتویات پوشه را روی GitHub Pages منتشر کنید.

## صدا و حالت آفلاین
صدا از قابلیت گفتار دستگاه/مرورگر (`SpeechSynthesis`) استفاده می‌کند. وجود صدای انگلیسی به تنظیمات دستگاه بستگی دارد. برای بهترین نتیجه، صدای انگلیسی را در تنظیمات تبدیل متن به گفتار اندروید نصب کنید. فونت وب ممکن است برای بار اول به اینترنت نیاز داشته باشد؛ در صورت قطع اینترنت فونت جایگزین دستگاه استفاده می‌شود.

## انتشار GitHub Pages
محتویات این پوشه را در مخزن GitHub قرار دهید و در Settings → Pages، منبع GitHub Actions را انتخاب کنید. فایل workflow در `.github/workflows/deploy.yml` قرار دارد.

## نکته‌ی نسخه
این بسته یک وب‌اپ/PWA است، نه فایل APK اندروید. برای APK باید مرحله‌ی جداگانه‌ی بسته‌بندی اندروید انجام شود.
